# SEO + AI visibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the CV readable by crawlers, add service and case-study pages, and publish everything search engines and AI assistants need (sitemap, robots, structured data, llms.txt, FAQs).

**Architecture:** The CV becomes a plain HTML page: `cv/page.html` (source, with `⟦markers⟧`) is baked with `cv/content.txt` into `cv/index.html` by `tools/build.py`. The same script generates the service pages, case pages, sitemap, robots and llms files from one data file, `data/site.json`. Generated files are committed, so the site also works from plain branch deploys, and a GitHub Actions workflow rebuilds them on every push to `main`.

**Tech Stack:** Python 3 standard library (build + checks), static HTML/CSS, GitHub Actions Pages deploy.

**Spec:** `docs/superpowers/specs/2026-10-25-site-revamp-design.md` (design tasks 4 and 5)

## Global Constraints

- Branches: `feat/seo` from `feat/services-readability`; `feat/ai-visibility` from `feat/seo`. Local only.
- The unbundled CV must look and behave identically. Its source is `../build/work/template.html`, which is byte-identical to the shipped bundle's template.
- "From" prices: website $200 · business systems $600 · Claude setup $250 · automations $400 · mobile panel $600 · marketing $300. Every package gets a free 20-minute audit, a fixed quote, 50% up front / 50% on delivery, 2 months of support, then $30/hr.
- Claim rules:
  - No client names, results or testimonials beyond what the CV and the public repo READMEs state.
  - Maiden Century AI Reports appears only as Saad's role.
- sameAs links: github.com/s-wasim and linkedin.com/in/s-waseem only. No marketplaces.
- No analytics. No hidden text.
- Service pages use the `/services` theme; case pages use the CV's retro theme.

## Review Focus

1. A `content.txt` edit with a typo'd header must make the build fail, not ship raw `⟦KEY⟧` markers. Test: `test_bake_missing_key_fails`.
2. The CV loads with no network access to unpkg (React must be served locally). Checked in the browser with requests to unpkg blocked.
3. A visitor arriving on `/cv` (no trailing slash) or on a case page with a hash. Relative asset paths must resolve. Checked in the browser.
4. The deploy artifact must not contain `tools/`, `tests/`, `docs/`, `data/` or `cv/page.html`. Test: `test_artifact_excludes_sources`.
5. Prices in pages, JSON-LD and llms.txt must all come from `data/site.json`. Test: `test_prices_consistent`.
