Portfolio-Summarizer

Three sources, fourteen tables, three tiers — raw Parquet, a DuckDB warehouse, and derived scores in their own partition. Loads are idempotent: append dedupes on a declared primary key, so a re-run costs nothing. The agent is the last mile, not the point.

What it does

An Airflow-orchestrated data platform that pulls SEC filings, prices and news every day, lands them in a 14-table DuckDB warehouse, scores each ticker from −100 to +100, and lets a Claude agent query it all through an MCP server.

How it works

  • Daily Airflow DAGs extract from SEC EDGAR, Yahoo Finance and Alpha Vantage.
  • Three tiers: raw Parquet, a 14-table DuckDB warehouse, and derived scores in their own partition.
  • Idempotent loads: appends dedupe on a declared primary key, so a re-run costs nothing.
  • A five-module scoring model blends price signals, EPS prediction, financial health and qualitative signals into one score.
  • An MCP server exposes named DuckDB queries as tools; a Claude agent (LangGraph) answers questions about the portfolio.
