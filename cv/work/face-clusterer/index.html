FaceClusterer

SigLIP global embeddings and InsightFace face embeddings, voted into a consensus across six thresholds. No model retraining, no labels.

$ python cluster.py ./album
  1. [load] 812 images
  2. [siglip] global embeddings 11.2s
  3. [insight] buffalo_l face embeddings
  4. [ensemble] consensus vote · 6 thresholds
  5. ✓ 7 stable identities → faces.txt

What it does

Point it at a folder of photos and it groups them by who is in them: SigLIP image embeddings and InsightFace face embeddings are clustered by a consensus vote across six thresholds, giving stable identity labels with no retraining, no labels and no fixed number of clusters.

How it works

  • Global image embeddings from SigLIP (google/siglip-so400m-patch14-384), batched and GPU-accelerated when available.
  • Face detection and face embeddings from InsightFace (buffalo_l).
  • Ensemble and consensus clustering across six thresholds, so identities stay stable on noisy photo sets.
  • Results are written into browsable folders and zipped.

By the numbers

  • 6 thresholds
  • 0 labels needed
  • 0 retraining

Stack

  • Python
  • SigLIP
  • InsightFace
  • NumPy
