What it does

A reference implementation of a four-agent system: a controller that proposes new ventures, a sandboxed code builder, capped-budget child agents, and a profit-blind ethics auditor that can veto the other three.

How it works

  • Mother agent: a stateful LangGraph controller that manages cash flow across three pots.
  • Code builder: stateless, generating tools inside a gVisor sandbox.
  • Ethics auditor: profit-blind, with a frozen prompt, and the power to veto.
  • Child agents: one per venture, each with a capped budget.
  • Frozen-config integrity: changing a protected file trips an alarm unless its hash is re-signed; an operator kill switch works over email.
