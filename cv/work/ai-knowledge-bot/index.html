What it does

A retrieval-augmented (RAG) app for getting up to speed on an unfamiliar codebase: ingest a repository, ask questions in plain English, and get answers grounded in the code with clickable file:line citations. When the code does not answer the question, it says so instead of guessing.

How it works

  • Ingests a local folder or a public GitHub repo, chunked with a line-window chunker.
  • Two retrieval modes: Postgres full-text search, or voyage-code-3 embeddings with pgvector.
  • A LangGraph flow rewrites the question, grades the retrieved chunks, then answers with citations.
  • At most three Claude calls per question.
  • An explicit 'not found' path, and every retrieved chunk and grade visible in the UI.

By the numbers

  • ≤3 Claude calls per question
  • file:line citations
  • 2 retrieval modes
